This directory contains records of significant architectural decisions made during the development of the p-adic VAE project.

## Purpose

The ADRs serve to:
- Document the *rationale* behind key design choices.
- Provide historical context for future contributors.
- Prevent regressions caused by refactors that might overlook subtle mathematical or geometric constraints.
